# MY PROGRESS — Railway deployment

## Railway settings
- Build: Nixpacks (automatic)
- Start command: `python run.py`
- Add a persistent volume mounted at `/data`.
- Add variables:
  - `BOT_TOKEN` — token from BotFather (keep it secret; do not commit it to GitHub)
  - `WEBAPP_URL` — the public HTTPS domain generated by Railway, e.g. `https://your-app.up.railway.app`
  - `DB_PATH` — `/data/my_progress.db`

The web server reads Railway's `PORT` automatically. `run.py` starts FastAPI and the Telegram bot polling process together.

## Important
Do not commit `.env` or share your bot token. Keep the persistent volume mounted at `/data`; otherwise SQLite data may not persist across deployments. Railway pricing and availability can change; check the current plan and usage before paying.
